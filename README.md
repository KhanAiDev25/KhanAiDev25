### Current work

**[MFCAD-Net](https://github.com/KhanAiDev25/MFCAD-Net)** is my MS thesis. It converts photographed
hand-drawn mechanical sketches into parametric CAD geometry. A two-class U-Net segments strokes into
straight and curved, then classical geometric fitting recovers lines, circles and arcs, and a constraint
layer enforces concentricity, equal radii, polar arrays and fillet tangency. Line F1 0.94 on a 115-part
held-out set.
